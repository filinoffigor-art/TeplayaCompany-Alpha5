# Тёплая Компания 4.0 — Alpha 5 Native Clean

Полностью чистая пересборка Android-приложения после аудита Alpha1–Alpha4.

## Архитектура
- Нативный Android Views / Java 17.
- **Никакого WebView / HTML / JavaScript.**
- applicationId: `ru.teplayakompaniya.tk4`
- minSdk 26
- targetSdk 34
- compileSdk 35
- версия: `5.0.0-alpha5`

## Почему так
Alpha1–Alpha3 были web-wrapper/WebView и давали пустой экран.
Alpha4 был нативным, но визуально и функционально не повторял согласованные прототипы.
Alpha5 пересобран заново с утверждённой логикой экранов.

## Что работает в Alpha5
- утверждённый главный экран руководителя;
- каждая KPI/цифра открывает детализацию;
- Объекты: сводка, фильтры, карточки, детализация;
- Создать объект;
- Техническое задание: монтажники, согласованная сумма каждому, план по дням, график оплат;
- системное Android «Поделиться ТЗ»;
- Монтажники: дни, выходные, закрытые объекты, начислено, аванс, к выдаче, инструмент, форма;
- Финансы: приход, расход, внутренний перевод, живые остатки;
- Аналитика: Оборот, Дебиторка, План поступлений, Осталось получить;
- Замеры: конверсия и контроль 14/21 дней;
- Инженеры / Менеджеры;
- Календарь загрузки по конкретным монтажникам;
- Настройки/роль/справочники;
- нижняя навигация.

## Финансовые правила
- Оборот = только фактические приходы.
- Дебиторка = только просроченный неоплаченный остаток этапов ТЗ.
- План поступлений = будущие неоплаченные этапы ТЗ.
- Внутренний перевод не является расходом компании.
- Согласованная зарплата монтажника не является фактом выплаты.
- Осталось выдать = начислено − авансы/частичные/финальные выплаты.

## Системные панели Android
Alpha5 не использует fullscreen/edge-to-edge.
Статус-бар и нижняя системная навигация — непрозрачные белые.
Контент приложения начинается ниже системной верхней панели и заканчивается выше нижней.
Размеры задаются в dp, интерфейс не привязан к Samsung S24 и адаптируется к Android-экранам разных размеров.

## Что пока НЕ подключено
Google Sheets/API. Alpha5 сначала подтверждает корректный UI/навигацию/формулы/Android-сборку.
После утверждения подключается реальная Google Sheets 4.0 без изменения экранов.

## Проверка GitHub Actions
Workflow:
`.github/workflows/build-alpha5.yml`

Он выполняет:
1. статические проверки;
2. JUnit тесты финансовых правил;
3. Android Lint;
4. сборку APK;
5. проверку наличия APK;
6. публикацию артефакта.

## Рекомендуемый чистый репозиторий
В `main` оставить только:
- `.github/`
- `app/`
- `build.gradle`
- `settings.gradle`
- `gradle.properties`
- `README.md`

Старые Alpha лучше сначала сохранить отдельным ZIP локально, а затем удалить из `main`.
